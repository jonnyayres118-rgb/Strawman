# Elastic Labs Opportunity Engine

Self-contained Next.js source package for GitHub + Vercel.

## Included
- Opportunity shortlist
- Editable Outside-In
- Capability Architect
- Smallest credible 2-3 person Core bias
- Conditional Flex
- Evidence-gated Scale
- Stress-test logic
- Core-first economics
- Client print/PDF
- Capability pattern library and learning states

## Run
npm install
npm test
npm run dev

## Deploy
Push all files to the root of a GitHub repository, connect/import that repo in Vercel, and keep the Vercel Root Directory as `./`.

No environment variables are required for this prototype.

Note: this is a reconstructed source build from the agreed specification, not a byte-for-byte export of the inaccessible older Vercel deployment.
